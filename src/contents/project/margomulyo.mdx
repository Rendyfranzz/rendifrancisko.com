## Overview

Welcome to the official website of **Desa wisata Margomulyo**!

This project was developed in collaboration with Margomulyo Tourism Village, showcasing the beauty and attractions of the village. The site provides visitors with an engaging and informative experience about local tourism.

## Key Features

- Village Profile - Comprehensive information about the tourism village
- Gallery - Photo gallery showcasing attractions and activities
- Interactive Map - Guide visitors to key locations in the village
- Contact Information - Easy way for visitors to get in touch
- News and Updates - Latest announcements and events

## Tech Stack

- **WordPress** - Content management system
- **Elementor** - Drag-and-drop page builder
- **Custom Theme** - Tailored design for the village

## Project Highlights

- **Client Satisfaction** - Met all client requirements and expectations
- **Visual Appeal** - Modern, welcoming design that reflects village charm
- **Mobile Responsive** - Accessible on all devices
- **Fast Loading** - Optimized for quick page loads

- Custom theme development for unique branding
