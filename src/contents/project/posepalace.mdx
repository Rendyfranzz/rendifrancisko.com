## Overview

**Pose Palace** is a web application designed for booking photography studio sessions. This project was created as a final assignment for a mobile programming course, building upon the experience gained from **Silhouette Studio**.

Pose Palace simplifies the process of scheduling and managing photo studio appointments with an enhanced user experience.

## Key Features

- Real-Time Slot Availability - View and select from available slots for studio sessions
- Easy Booking Process - Streamlined process for reserving studio time
- Detailed Studio Information - Comprehensive details about the studio's amenities and equipment
- Responsive Design - Seamless user experience across various devices

## What Users Can Do

- Browse available time slots and select preferred session times
- Book studio sessions with just a few clicks
- Explore studio amenities and features
- Manage their bookings and appointments

## Tech Stack

- **React** - JavaScript library for building the user interface
- **Redux** - State management for smooth data flow
- **Tailwind CSS** - Modern and responsive design

## Technical Highlights

- **Advanced State Management** - Efficient application state handling with Redux
- **Responsive Layout** - Adapts well to different devices and screen sizes
- **Intuitive Booking Interface** - Minimizes user errors and improves usability
- **Component-Based Architecture** - Modular and maintainable code

## Challenges Faced

- **State Management** - Efficiently managing application state with Redux
- **Responsive Design** - Ensuring layout and functionality adapt to all devices
- **User Interaction** - Designing an intuitive booking interface
