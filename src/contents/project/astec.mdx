## Overview

Welcome to **ASTEC 2024** at SMA Al-Hikmah Surabaya!

This website serves as your gateway to one of the most exhilarating competition events of the year. With a total prize pool of up to **50 million rupiah**, ASTEC 2024 invites participants to engage in exciting challenges and showcase their talents.

## Key Features

- Easy Registration - Streamlined registration process for multiple competitions
- Event Schedule - Complete timeline of events and important dates
- Results Dashboard - Real-time competition results and rankings
- Responsive Design - Works seamlessly on all devices

## Tech Stack

- **Next.js** - Server-side rendering and SSG for performance
- **TypeScript** - Type safety and better developer experience
- **Tailwind CSS** - Modern, responsive styling
- **Framer Motion** - Smooth animations and transitions

## Tech Details

- Built with **Next.js 14** App Router
- **Server Components** for optimal performance
- **Framer Motion** animations for engaging UX
- **Responsive design** for mobile and desktop

## Live Demo

Visit the live website at **[astec.smaalhikmah.com](https://astec.smaalhikmah.com/)** to register for competitions, view event details, and more!
