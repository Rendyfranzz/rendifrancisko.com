## Why Tailwind CSS?

Tailwind CSS has gained massive popularity for its utility-first approach. Instead of writing custom CSS, you apply pre-defined utility classes directly in your markup.

## Best Practices

### 1. Use @apply Sparingly

While `@apply` allows extracting common classes into reusable components, overusing it defeats Tailwind's purpose. Use it only for truly repetitive patterns.

```tsx
// Good: Using utilities directly
<button class="px-4 py-2 bg-blue-500 text-white rounded">
  Click me
</button>

// Avoid: Overusing @apply for everything
.btn-primary {
  @apply px-4 py-2 bg-blue-500 text-white rounded;
}
```

### 2. Leverage Config for Consistency

Customize your `tailwind.config.js` to define your design system:

```js
module.exports = {
  theme: {
    extend: {
      colors: {
        primary: '#3B82F6',
        secondary: '#10B981',
      },
      fontFamily: {
        sans: ['Inter', 'sans-serif'],
      },
    },
  },
};
```

### 3. Use clsx and tailwind-merge

For conditional classes, use these utilities to avoid conflicts:

```tsx
import { clsx } from 'clsx';
import { twMerge } from 'tailwind-merge';

function cn(...inputs) {
  return twMerge(clsx(inputs));
}

// Usage
<div className={cn('base-class', isActive && 'active-class')} />
```

### 4. Organize Classes Logically

Group related classes for readability:

```tsx
<div
  className="
    flex flex-col items-center justify-center
    p-4 m-2
    bg-white dark:bg-gray-900
    rounded-lg shadow-lg
    hover:shadow-xl transition-shadow
  "
/>
```

### 5. Use the Official Typography Plugin

For prose content, `@tailwindcss/typography` provides the `prose` class:

```tsx
<article className="prose dark:prose-invert lg:prose-lg">
  {children}
</article>
```

## Common Pitfalls

- **Overly long class strings** - Extract to components when unwieldy
- **Not using responsive prefixes** - Remember `md:`, `lg:` prefixes
- **Ignoring dark mode** - Use `dark:` prefix for dark theme support
- **Hardcoding values** - Use theme config instead of arbitrary values

## Conclusion

Mastering Tailwind CSS takes time, but following these best practices will help you write cleaner, more maintainable styles. The key is finding the right balance between utility classes and component abstraction.
